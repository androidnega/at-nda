CSS / layout (Tailwind):
  - Panel max width on large screens: min(100%, 32rem) ≈ 512px column
  - Min heights:
      mobile:  min-h 200px (sm: 240px)
      desktop: min-h min(85vh, 28rem)  → up to ~448px tall
  - Image: position absolute, inset-0, w-full h-full, object-cover (crops to fill)

  - Brand overlay: partials/atenda-hero-brand.blade.php (text "a-tenda", not an image)

Parent layout (home.blade.php / login-password / set-password):
  - Split card: login form ~22rem wide on left; hero on right on lg+ breakpoints
  - Card overlaps hero slightly: lg:-mr-8 xl:-mr-12, z-index card 20
  - Container max-w-5xl centered

Performance attributes:
  - loading="eager" only on home (first paint); else lazy
  - decoding="async"
  - referrerpolicy="no-referrer-when-downgrade"


RECOMMENDATIONS FOR REPLACEMENT (web hero)
------------------------------------------
  - Target aspect ratio: ~16:9 to ~2:1 (current 600×327 ≈ 1.83:1 works)
  - Minimum width for retina: 1024–1200px wide source (display scales down/crops)
  - Safe area: keep faces/subjects centered; edges will crop with object-cover
  - Host on your own CDN or public/storage; set AUTH_HERO_IMAGE=https://...
  - Avoid hotlinking Shutterstock in production (licensing)

================================================================================
5. ENV / DEPLOY CHECKLIST
================================================================================

To change web login image:
  1. Upload image to accessible HTTPS URL (or same-origin path).
  2. Set in production .env: AUTH_HERO_IMAGE=https://your-domain/path/image.jpg
  3. php artisan config:clear (if config cached)

To change mobile login header icon:
  1. Replace at-end_frontend_app/branding/app_icon.png (keep 1024×1024 recommended).
  2. flutter pub get && dart run flutter_launcher_icons
  3. Rebuild app.
